# Git 日志管理 Agent 应用

一个本地 Web 应用，用于管理多个 Git 项目，查看提交记录，并自动生成日报、周报、月度版本特性总结。

## 功能特性

- **多项目管理**：可添加多个 Git 仓库，通过系统目录选择器「打开本地目录」快速添加，也支持手动输入路径
- **分支切换**：顶部下拉框可切换查看本地/远程任意分支的提交记录
- **提交记录查看**：按时间范围（今天/近 3 天/近 7 天/近 30 天/全部）切换查看提交，支持按作者、文件筛选
- **统计概览**：提交数、参与人数、改动文件数、新增/删除行数一目了然
- **贡献者 & 热门文件**：自动统计贡献者排名和改动最频繁的文件
- **报告生成（两种方式可选）**：一键生成日报、周报、月度版本特性总结。默认使用固定模板（按约定式提交前缀分类归纳）；可切换到「AI 总结」模式，由 AI 智能归纳零散的提交信息、合并相近主题。均支持复制、下载 Markdown、导出 PDF
- **提交详情 + Diff 预览**：点击任意提交查看完整 diff 统计，切换到「代码 Diff」标签可高亮预览具体改动
- **提交趋势图**：近 30 天提交频率折线图，一眼看团队活跃度
- **异常提交告警**：自动检测大提交、空提交信息、提交信息过短、深夜提交等异常
- **贡献者画像**：点击贡献者查看其提交数、改动行数、提交类型分布、活跃时段、常改文件等
- **AI 语义搜索**：输入自然语言（如「谁改过登录逻辑」）智能检索相关提交
- **数据持久化**：项目列表保存在本地 JSON 文件，重启后自动加载

## 快速开始

### 环境要求

- macOS（目录选择器基于 `osascript`）
- Node.js（≥ 18，推荐 20+）
- 系统已安装 `git`

### 安装依赖

```bash
cd git-log-manager
npm install
```

### 启动

开发模式（前后端热更新）：

```bash
npm run dev
# 前端 Vite: http://localhost:5173
# 后端 API: http://localhost:4399
```

生产模式（先构建，再启动）：

```bash
npm run build
npm start
# 访问 http://localhost:4399
```

如需自定义端口：

```bash
PORT=8080 npm start
```

> **热更新说明**：
> - **前端** `src/` 下的 React 组件改动，由 Vite HMR 即时热替换，无需刷新。
> - **后端** `server/` 下的改动，由 `node --watch` 自动重启生效。

## 使用说明

1. 点击左侧「＋ 添加项目」，在弹出的系统目录选择器中选择 Git 仓库目录（也可点「手动输入路径」直接输入）
2. 添加后自动切换到该项目，展示当前分支的提交概览
3. 顶部切换时间范围，查看不同时间段的提交
4. 点击「日报 / 周报 / 月度总结」生成对应报告，可复制或下载
5. 点击任意提交查看详细改动
6. 点击右侧「贡献者」列表中的成员，查看其**贡献者画像**（提交数、改动行数、提交类型分布、活跃时段、常改文件等）
7. 使用顶部「AI 语义搜索」框，输入自然语言（如「谁改过登录逻辑」），AI 智能检索相关提交
8. 查看提交记录上方的「提交趋势 / 异常告警」面板，了解团队活跃度和潜在风险

## 项目结构

```
git-log-manager/
├── server/                # 后端（Node + Express）
│   ├── index.js           # 服务入口 + 静态托管
│   ├── routes.js          # API 路由（按功能拆分）
│   ├── git.js             # git 命令封装与数据查询
│   └── store.js           # 项目列表持久化
├── src/                   # 前端（React + TypeScript）
│   ├── main.tsx           # 入口
│   ├── App.tsx            # 主组件（布局 + 状态）
│   ├── components/        # 各功能组件
│   ├── api/               # 接口封装 + 云端 LLM + 报告逻辑
│   ├── types/             # TypeScript 类型定义
│   └── utils.ts           # 工具函数
├── index.html             # Vite 入口 HTML
├── vite.config.js         # Vite 配置（开发代理）
├── tsconfig.json          # TypeScript 配置
├── data/
│   └── projects.json      # 项目列表持久化文件
└── dist/                  # 前端构建产物（生产模式）
```

## 技术说明

- **前端**：React 18 + TypeScript + Ant Design 5 + Vite，组件化开发，类型安全
- **后端**：Node + Express，按模块拆分路由；通过 `git -C <路径>` 调用系统 git 命令
- **提交分类**：按约定式提交前缀（feat/fix/perf/refactor/docs/test/chore/style）自动分类
- **AI 能力**：通过 WorkBuddy 云服务 LLM API（keyless）实现报告智能总结和语义搜索精排

## 注意事项

- 「移除项目」仅从列表移除，**不会删除磁盘上的任何文件**
- 目录选择器功能依赖 macOS，其他系统请使用「手动输入路径」
